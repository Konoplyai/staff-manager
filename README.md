# Облік працівників підприємства

Курсова робота з дисципліни «Об'єктно-орієнтоване програмування на мові Java».
Виконав студент групи Ін-42/1 Конопля Іван, СумДУ, 2026. Варіант 1.

Застосунок з графічним інтерфейсом JavaFX для роботи з базою даних PostgreSQL,
у якій зберігаються підрозділи підприємства та їх працівники.

## Можливості

- вхід з логіном і паролем користувача PostgreSQL;
- перегляд, додавання, редагування та видалення працівників і підрозділів;
- пошук працівників за прізвищем або його фрагментом;
- сортування списку працівників за ПІБ (за українським алфавітом, в обидва боки);
- нарахування премії працівникам вибраного підрозділу у відсотках від заробітної плати
  (зміни записуються в базу в одній транзакції, ведеться історія премій);
- розрахунок середньої, мінімальної та максимальної заробітної плати підрозділу,
  діаграма середньої заробітної плати за підрозділами;
- експорт усіх даних у файл JSON та імпорт з файлу JSON;
- перевірка введених даних і зрозумілі повідомлення про помилки.

## Технології

Java 21, JavaFX 21, JDBC (драйвер PostgreSQL 42.7), PostgreSQL 17, Gson 2.11, Maven, JUnit 5.

## Структура

- `model` - класи предметної області (Employee, Department, BonusRecord, DepartmentStatistics);
- `db` - підключення до бази та DAO на JDBC з PreparedStatement;
- `service` - прикладна логіка, перевірка даних, сортування;
- `io` - експорт та імпорт JSON;
- `ui` - вікна і вкладки JavaFX;
- `db/schema.sql`, `db/data.sql` - створення таблиць і початкові дані;
- `examples` - приклади файлів JSON для імпорту.

## Запуск

1. Створити базу і користувача (від імені postgres):

       CREATE ROLE company_user LOGIN PASSWORD 'your_password';
       CREATE DATABASE company_db OWNER company_user;

2. Створити таблиці та заповнити їх:

       psql -U company_user -d company_db -f db/schema.sql
       psql -U company_user -d company_db -f db/data.sql

3. Зібрати і запустити:

       mvn clean compile
       run.cmd

   або `mvn javafx:run`. Параметри сервера за замовчуванням задаються в `app.properties`,
   пароль вводиться у вікні входу.
